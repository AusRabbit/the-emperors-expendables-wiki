An officer-grade Imperial code cylinder carried by [[eleena-daru]]. She kept it concealed for a long time, then showed it to [[telsa-brie]], then used it openly to force a lockdown bulkhead during the escape toward [[bay-nine]].

[[elo-kesh]] knows it exists. Whether it survived the capture hasn't been settled.
